## Akıllı Müşteri Yönetim ve Analiz Sistemi (Telco Customer Churn)

Bu projede Telco Customer Churn veri seti kullanılarak müşteri kaybı (churn) analizi yapılmıştır.

### Kullanılan Teknolojiler
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Google Colab

### Yapılan İşlemler
- Veri setinin yüklenmesi
- Veri analizi
- Eksik verilerin temizlenmesi
- Kategorik verilerin sayısallaştırılması
- Veri görselleştirme
- Logistic Regression modeli
- Random Forest modeli
- Model performans değerlendirmesi

### Sonuçlar

#### Logistic Regression
- Accuracy: 0.7882
- AUC: 0.7022

#### Random Forest
- Accuracy: 0.7896
- AUC: 0.6930
